## Dead Letter Events

The dead-letter list holds provider replies Pragmatiks could not read, kept for investigation.

### List

```bash
pragma ops dead-letter list
```

Filter by provider:

```bash
pragma ops dead-letter list --provider gcp
```

### Show Details

```bash
pragma ops dead-letter show <event-id>
```

### Delete

Delete a single event:

```bash
pragma ops dead-letter delete <event-id>
```

Delete all events for a provider:

```bash
pragma ops dead-letter delete --provider gcp
```

Delete all events:

```bash
pragma ops dead-letter delete --all
```
