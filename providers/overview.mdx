Resources are built and maintained by providers. The catalog lists every provider you can install; install one with a single command and its resource types become available to your organization.

## Available Resources

All providers below are built and maintained by Pragmatiks.

| Resource | Description |
|----------|-------------|

| [`agno/team`](/providers/agno/team) | Multi-agent team with coordinated members |
| [`agno/models/anthropic`](/providers/agno/models) | Anthropic Claude model configuration |
| [`agno/models/openai`](/providers/agno/models) | OpenAI GPT model configuration |
| [`agno/tools/mcp`](/providers/agno/tools) | MCP server tool integration |

### Pragma Provider

Platform-managed resources from the published `pragmatiks/pragma` provider, installed in every organization.

| Resource | Description |
|----------|-------------|
| `pragma/secret` | Sensitive key-value data |
| `pragma/config` | Non-sensitive configuration |
| `pragma/file` | File storage |

## Browsing Resources

Browse the catalog, inspect a provider, and install it with the CLI:

```bash
pragma providers list
pragma providers list --query postgres
pragma providers info pragmatiks/gcp
pragma providers install pragmatiks/gcp
pragma providers list --installed
```

See [`pragma providers`](/cli/providers) for every option.
