---

Keep your installed providers up to date or remove them when no longer needed.

## Prerequisites

- Install the CLI: see [Installation](/cli/installation)
- Authenticate: `pragma auth login`
- Verify context: `pragma config current-context`

## Checking Installed Versions

View your installed providers, their state and the version each serves:

```bash
pragma providers list --installed
```

Compare with the versions a provider has published:

```bash
pragma providers versions pragmatiks/qdrant
```

## Upgrading a Provider

### Upgrade to Latest

```bash
pragma providers upgrade pragmatiks/qdrant
```

```text
Upgrading: pragmatiks/qdrant -> latest

Upgrade pragmatiks/qdrant to latest? [y/N]: y
Upgraded: pragmatiks/qdrant -> v1.2.0
Follow it with: pragma providers history pragmatiks/qdrant
```

### Upgrade to a Specific Version

```bash
pragma providers upgrade pragmatiks/qdrant --version 1.2.0
```

### Downgrade

```bash
pragma providers downgrade pragmatiks/qdrant --version 1.1.0
```

### Skip Confirmation

```bash
pragma providers upgrade pragmatiks/qdrant -y
```

### What Happens During an Upgrade

An upgrade or downgrade is queued, then starts the target version, and ends **Running** or **Failed**, like an install (see [Installation Lifecycle](/store/installing#installation-lifecycle)). The installed version keeps serving your resources until the new one runs. Follow it with:

```bash
pragma providers history pragmatiks/qdrant
```

An upgrade or downgrade is refused while another operation on the provider is running; wait for it to finish, then run the command again. A failed installation cannot be downgraded; install the version you want instead:

```bash
pragma providers install pragmatiks/qdrant --version 1.1.0
```

## Uninstalling a Provider

### Basic Uninstall

```bash
pragma providers uninstall pragmatiks/qdrant
```

```text
Provider: pragmatiks/qdrant

Are you sure you want to UNINSTALL provider? [y/N]: y
Uninstalled: pragmatiks/qdrant
```

While it is removed, the provider shows **Uninstalling** in `pragma providers list --installed`. Its history stays available for 30 days.

<Warning>
If the provider has active resources, the uninstall fails. Delete the resources first, or use `--cascade`.
</Warning>

### Cascade Delete

Uninstall the provider and delete all resources it manages:

```bash
pragma providers uninstall pragmatiks/qdrant --cascade
```

The `--cascade` flag deletes every resource created by the provider before removing the provider itself.

### Skip Confirmation

```bash
pragma providers uninstall pragmatiks/qdrant --cascade -y
```
