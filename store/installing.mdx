---
title: "Installing Providers"
description: "Install providers into your organization and follow each installation until it runs"
---

Installing a provider from the store makes all its resource types available in your organization.

## Prerequisites

- Authenticated with the platform: `pragma auth login`
- Active context: `pragma config current-context`

## Install via CLI

### Basic Install

Install the latest version:

```bash
pragma providers install pragmatiks/qdrant
```

```text
Provider: Qdrant (pragmatiks/qdrant)
Version:  1.2.0

Install this provider? [y/N]: y
Install queued: pragmatiks/qdrant v1.2.0
Follow it with: pragma providers history pragmatiks/qdrant
```

The command prints the version the installation targets. The installation then continues on its own; follow it with `pragma providers history` or `pragma providers list --installed`.

### Install a Specific Version

```bash
pragma providers install pragmatiks/qdrant --version 1.1.0
```

### Pass Configuration

Configuration values reach only this provider:

```bash
pragma providers install pragmatiks/qdrant --config SOME_KEY=some_value
pragma providers install pragmatiks/qdrant --config-file config.yaml --config OVERRIDE_KEY=value
```

### Skip Confirmation

Use `-y` to skip the confirmation prompt (useful in scripts):

```bash
pragma providers install pragmatiks/qdrant -y
```

## Install via Web UI

In the Pragmatiks dashboard, navigate to the **Store** tab, select a provider and click **Install**. The provider page then shows the installation's state and its history.

## Installation Lifecycle

An install, upgrade or downgrade moves through these states:

| State | Meaning |
|-------|---------|
| **Queued** | The operation is accepted and waits to start |
| **Starting** | Pragmatiks is preparing and starting the provider at the target version |
| **Running** | The provider serves its resources |
| **Failed** | The operation did not finish; its message says why |

Check the state of every installed provider:

```bash
pragma providers list --installed
```

The table shows each provider's **State**, the **Version** it serves (a dash until it first runs), its latest **Operation** with the version it targets, and the failure **Message** when it failed, or when a failed upgrade or downgrade left it Running on the installed version.

See every transition of one provider, newest first:

```bash
pragma providers history pragmatiks/qdrant
```

The history lists the time, the transition (such as `Queued -> Starting`), the operation, the version, the message and, for a failure, its cause. It is kept for 30 days, also after the provider is uninstalled.

Once a provider is **Running**, its resource types are available:

```bash
pragma resources types
```

## When an Installation Fails

A failed installation shows its reason in `pragma providers list --installed`, in `pragma providers history`, and on the provider page in the web console. For example:

```text
Installing acme/pipeline 2.0.0 did not finish in time. Install it again.
```

Recover by installing it again, at the version you want:

```bash
pragma providers install acme/pipeline --version 2.0.0
```

In the web console, the **Install again** button on the provider page does the same.

<Note>
Some refusals stop an install before it starts. Installing a provider that embeds other providers names the missing ones and the command to install each. A version that has not finished publishing, or whose publish failed, cannot be installed.
</Note>
